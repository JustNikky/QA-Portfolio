## TC-CART-006 - Multiple products can be added to cart
---

| **Field** | **Value** |
|---|---|
| **Test case ID** | TC-CART-006 |
| **Test type** | Functional |
| **Title** | Multiple products can be added to cart |
| **Module** | Cart |
| **Priority** | High |
| **Preconditions** | User is logged in and is on the Products page. |
| **Test data** | Any 2–3 products, e.g. Sauce Labs Backpack, Sauce Labs Bike Light, Sauce Labs Bolt T-Shirt |
| **Steps** | 1. Click Add to cart for `Sauce Labs Backpack`.<br><br>2. Click Add to cart for `Sauce Labs Bike Light`.<br><br>3. Click Add to cart for `Sauce Labs Bolt T-Shirt`.<br><br>4. Observe the cart icon. |
| **Expected result** | Each selected product is successfully added to the cart. The cart icon displays the correct number of items (3). The selected products remain in the cart with the correct names and quantities.|
| **Actual result** | Each selected product was successfully added to the cart. The cart icon displayed the correct number of items (3). The selected products remained in the cart with the correct names and quantities. |
| **Status** | **PASS** |
| **Defect** | N/A |
